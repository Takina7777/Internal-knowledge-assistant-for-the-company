一、项目定位
--------------------------------------------------------------------
企业内部知识问答助手：员工以自然语言提问（公司制度、流程、文档），
系统基于知识库检索 + 大模型生成回答，回答强制带引用（文档出处）。
目标形态：Web 门户 + 企业微信机器人双入口（企微为 Phase 2）。


二、总体架构（分层设计）
--------------------------------------------------------------------
[接入层]     Web 门户（React）  |  企业微信机器人(Phase 2)  |  API(供集成)
                    |                      |                      |
[网关层]     Nginx(部署期)  |  JWT 认证 / SSO(Phase 2)  |  限流 / 审计
                    |
[Agent编排层] LangGraph 状态机：retrieve -> generate -> guard
              （扩展：intent 路由、工具调用、人审闸门，均预留）
                    |
[检索层RAG]   查询向量化(bge-m3) -> 向量检索(Chroma/Qdrant) -> Rerank(预留)
              -> 权限过滤(where ACL，Phase 2) -> 引用溯源
                    |
[知识管道]    文档源接入(Confluence/飞书/本地) -> 解析 -> 分块 -> 向量化 -> 入库
              （同步脚本 ingest.py 已实现；文档源 connector 为 Phase 2）
                    |
[数据层]      Chroma(向量)  |  SQLite->PostgreSQL(用户/会话/审计)  |  Redis(缓存/队列)
                    |
[可观测]      Trace 抽象(noop 已实现 / Langfuse Phase 2)  |  指标看板  |  评测集
                    |
[异步管道]    Celery + Redis：文档入库、反馈落库(Phase 2)


三、技术栈选型
--------------------------------------------------------------------
  问答模型      deepseek-v4-flash（OpenAI 兼容 API）
  向量模型      Ollama bge-m3（本地，1024 维）
  后端          Python 3.13 / FastAPI / Pydantic v2
  Agent 编排    LangGraph 1.x（状态机 + InMemorySaver，生产换持久化 checkpointer）
  向量库        Chroma（现用） -> Qdrant（Phase 2，抽象层已预留）
  异步管道      Celery 5.6 + Redis 7
  认证          bcrypt + pyjwt（JWT HS256，access 2h / refresh 7d 轮换）
                -> SSO/OIDC（Phase 2，AuthProvider 抽象已预留）
  前端          React 18 / TypeScript / Vite 6 / Ant Design 5 / zustand
  文档解析      PyMuPDF(pdf) / python-docx(docx) / markdown-it 体系
  可观测        抽象接口（noop 实现；Langfuse 自托管 Phase 2）

五、核心流程
--------------------------------------------------------------------
1. 问答链路（已实现）
   用户提问 -> [JWT 校验] -> LangGraph:
     retrieve: 问题向量化(bge-m3) -> Chroma 检索 Top-5 -> 组装引用
     generate: 检索片段+Prompt -> deepseek-v4-flash 生成（带[1][2]引用）
     guard   : 空回答兜底 + 敏感信息脱敏
   -> SSE 流式返回（citations 事件 -> token 事件 -> done）

2. 文档入库（已实现）
   上传(md/txt/pdf/docx) -> Celery 异步任务
   -> 解析 -> Markdown 分块(标题层级+重叠) -> bge-m3 批量向量化
   -> Chroma 写入（幂等：先删旧再写）-> 任务状态可轮询

  ✅ 前端令牌自动刷新（401 无感续期，7 天有效）

【未完成 ⏳（按优先级排序）】
  ⏳ 1. SSO/OIDC 对接（Phase 2）
       实现 deps.py 的 OidcAuthProvider；AUTH_PROVIDER=oidc；
       需要公司 IdP（Keycloak/ADFS/自建）的 issuer/client_id/client_secret。
  ⏳ 2. 检索权限过滤（ACL）
       用户角色/部门注入 retrieve 节点的 where 条件，
       实现"检索不到=答不出来"的权限隔离；用户表增加部门/密级字段。
  ⏳ 3. 企业微信机器人（Phase 2）
       按 app/wecom/ 规划实现：crypto(WXBizMsgCrypt 加解密)、
       client(access_token 缓存+主动发消息)、handler(消息->agent->5秒内回success)；
       需企业微信自建应用 corpid/agentid/secret + 公网回调 URL + Token/AESKey。
  ⏳ 4. 可观测 Langfuse 自托管
       实现 core/observability.py 的 LangfuseTracer；
       docker 部署 Langfuse；OBSERVABILITY_PROVIDER=langfuse。
  ⏳ 5. 检索增强
       混合检索（BM25+向量融合）；Rerank 重排（bge-reranker 或云端）；
       检索参数可调（Top-K/阈值/融合权重）。
  ⏳ 6. 会话记忆持久化
       LangGraph checkpointer 换 PostgresSaver/SqliteSaver（当前 InMemorySaver）；
       多轮上下文显式注入（当前单轮检索问答）。
  ⏳ 7. 向量库 Qdrant 迁移
       实现 qdrant_store.py（协议在 base.py）；VECTOR_STORE_BACKEND=qdrant；
       数据量超过 Chroma 承载或需要 HA 时执行。
  ⏳ 8. 用户库 PostgreSQL 迁移
       替换 db/user_store.py 实现（接口不变）；
       用户管理 API（创建/禁用/角色分配）。
  ⏳ 9. 评测体系
       评测集（200~500 条真实问题，含越权/幻觉陷阱类）；
       自动回归（模型/Prompt/索引变更必须跑）；
       成本与成功率双指标看板。
  ⏳ 10. 反馈闭环（数据飞轮）
       前端 👍👎 反馈落库（POST /api/v1/feedback）；
       纠错/漏检上报 -> 沉淀进评测集 -> 定期回归优化。
  ⏳ 11. 文档源接入
       Confluence / 飞书文档 / SharePoint connector；
       增量同步（事件驱动 + 定时兜底）。
  ⏳ 12. 部署与运维
       Docker Compose 一键部署全套（后端+Celery+前端+Redis[+Langfuse]）；
       HTTPS、企业微信公网回调（内网穿透/反代）；
       日志归档、审计看板、限流策略。
  ⏳ 13. 多轮对话体验完善
       上下文记忆 + 追问理解；会话列表/历史查询（当前仅单会话）。
  ⏳ 14. 主动工具调用
       查工单/查假期/查审批（Function Calling），人审闸门（高风险动作审批）。

八、注意事项
--------------------------------------------------------------------
  1. 后端服务必须由用户自己的终端运行（Agent 会话托管的进程不持久）。
  2. backend/.env 含密钥，已被 gitignore；.env.example 只放占位符。
  3. 管理员初始密码在 .env（ADMIN_PASSWORD），上线前务必修改。
  4. CELERY_DEV_NO_LUA：真实 Redis 必须 false；fakeredis 开发模式才置 true。
  5. 升级 Embedding 模型需全量重建索引（chunk 向量维度必须一致）。
  6. 生产环境 JWT_SECRET 必须替换为随机长串。
  7. 本沙箱环境限制：esbuild 需全权限；docker CLI 需全权限（命名管道）。
